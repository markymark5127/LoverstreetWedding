# Loverstreet Wedding Ceremonies

Redesigned website for Katelyn Overstreet, authorized Virginia marriage celebrant based in Forest, VA.

## Preview

Open `index.html` or run:

```bash
python3 -m http.server 8080
```

## GitHub Pages

Repo Settings → Pages → Deploy from branch `main` / root.

Optional: point `loverstreetweddingceremonies.com` at GitHub Pages and add a `CNAME` file.
